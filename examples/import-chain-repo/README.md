# import-chain-repo (defanged demo)

`CLAUDE.md` looks clean and imports `docs/style.md`, which imports `shared/team-rules.md`. That file hides an instruction in invisible characters, so a scanner that only looks at agent files never sees it. `docs/setup.md` also imports a `.env` file and a path outside the repository.

    ghostrules scan --no-follow-imports .   # 0.1 behaviour: nothing found
    ghostrules scan .                       # the payload, with its import chain
    ghostrules context src/api/users.ts --agent claude-code

Every payload here is **defanged**: `*.example` domains and a fake token. Nothing in this
directory does anything when read by a human or an agent. It is generated by
`scripts/make_demo.py`, so the invisible characters are reproducible.
