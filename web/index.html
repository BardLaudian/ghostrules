Drop a folder here or choose one.

Only agent files (AGENTS.md, CLAUDE.md, rules, MCP configs…) and the files they import are read, up to 5 MB. Nothing is uploaded.

This is the only feature that uses the network, and it talks only to GitHub (api.github.com and raw.githubusercontent.com). It makes unauthenticated requests: GitHub allows 60 per hour per IP address.

Runs entirely in your browser. No data is sent anywhere, no analytics, no cookies. (Exception: the GitHub tab fetches files from GitHub.)
