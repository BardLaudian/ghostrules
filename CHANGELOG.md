# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Project scaffold: packaging, CI, `ghostrules version`.
- Core engine: models, Unicode utilities, target discovery, config loading, scanner pipeline
  (rule registry, suppressions, decoded hidden-text pass).
- Rules GR001-GR006: Unicode tag characters, bidi controls, zero-width characters, variation-selector
  steganography, hidden HTML comments, mixed-script homoglyphs.
- Rules GR010-GR016: instruction override, concealment, remote code execution, data
  exfiltration, sensitive file access, encoded payloads, agent safety bypass (English + Spanish);
  hidden text decoded by other rules is re-scanned with a severity bump.
- Rules GR101-GR108: hardcoded secrets, unpinned packages, insecure transport, broad filesystem
  scope, shell wrappers, dangerous Docker options, over-permissive agent settings, auto-trusted
  MCP servers; findings point at the exact value in the file.
- Central secret masking: no secret is ever printed, in any field of a finding or diagnostic.
- CLI: `scan` (default command), `reveal`, `clean`, `rules`, `version`; reports as table, JSON,
  SARIF 2.1.0 (validated against the official schema) and Markdown.
- Demo repositories `examples/poisoned-repo` (every rule fires) and `examples/clean-repo`
  (no findings), generated by `scripts/make_demo.py`; `demo/demo.tape` to record the README GIF.
- GitHub Action (`action.yml`, composite): SARIF upload, job summary, fail-on gate; pre-commit
  hook; CI smoke test, self-test and tag-triggered release workflows (PyPI Trusted Publishing).
- README, `SECURITY.md`, `CONTRIBUTING.md`, issue forms (new rule, false positive) and a rules
  table generated from the registry (`scripts/gen_rules_table.py`) that a test keeps in sync.
- `scripts/make_fixtures.py` generating reproducible, defanged fixtures.
